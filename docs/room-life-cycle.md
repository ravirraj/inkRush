## Entry
user opens home page
enters nickname
session initialized
user creates or joins room

## Lobby
first player becomes host
players can join until room useful
room remains in lobby state until host starts

## In Game
room transitions to in-game
players assigned turn order
rounds start

## Disconnection
disconnected player marked temporarily offline
host transfer if needed
drawer disconnect handled specially

## Cleanup
empty room gets removed after timeout or immediately
This doc becomes extremeley useful later.
