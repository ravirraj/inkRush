# inkRush

A real-time multiplayer drawing and guessing game inspired by Skribbl.io.

## Features

- Real-time drawing
- Room based multiplayer
- Invite links
- Live chat
- Word selection system
- Hints during gameplay
- Scoring system
- Round summaries
- Final leaderboard
- Play again functionality

---

## Tech Stack

### Frontend
- React
- Vite
- WebSockets

### Backend
- Go
- Gin
- Gorilla WebSocket
